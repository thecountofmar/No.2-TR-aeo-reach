# Contributing to AEO-reach Core

AEO-reach Core welcomes contributions in five areas:

1. Channel compilers
2. Scorers and evaluators
3. Industry templates
4. Agentic web adapters
5. Evaluation suites

## Contribution principles

- Business facts should remain verifiable.
- Do not add fake claims, fake reviews, or manipulative content.
- Each compiler should define expected output artifacts.
- Each scorer should explain what it measures and why.
- Tests or example outputs are required for new compilers.
